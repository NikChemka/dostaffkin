
# Dostaffkin — сервис доставки посылок

## О проекте

Приложение для расчёта стоимости доставки, оформления заявок и отслеживания посылок.  
Интеграция с Яндекс.Картами для построения маршрутов, адаптивный интерфейс.

## Основной функционал

- **Расчёт доставки** — выбор маршрута (адреса через подсказки), размера посылки (XS–MAX), скорости (обычная/приоритетная)
- **Оформление заявки** — отправка контактов и параметров на API
- **Отслеживание** — проверка статуса по номеру отправления

### API эндпоинты

| Метод | URL | Описание |
|-------|-----|----------|
| POST | `https://testologia.ru/delivery/create` | Создание заявки |
| GET  | `https://testologia.ru/delivery/info?id={id}` | Получение статуса |

## Технологический стек

- **Фронт**: Angular 19 (standalone components, signals, reactive forms)
- **Карты**: Yandex.Maps API 2.1
- **Стили**: CSS (flex, grid, медиазапросы)
- **HTTP клиент**: Angular HttpClient
- **Сборка**: Angular CLI

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm start

# Сборка проекта
npm run build
```
